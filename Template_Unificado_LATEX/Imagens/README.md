# Diretório de Imagens e Diagramas Vetoriais

Armazene aqui os diagramas e imagens referenciados pelos documentos LaTeX.

### Recomendações:
- **Formatos preferenciais:** `.pdf` (vetorial de alta resolução) e `.png` (para capturas de tela e mockups);
- **Convenção de nomenclatura:**
  - `uc_*.pdf` -> Diagramas de casos de uso
  - `cls_*.pdf` -> Diagramas de classes
  - `seq_*.pdf` -> Diagramas de sequência
  - `dsm_*.pdf` -> Diagramas de máquina de estados
  - `act_*.pdf` -> Diagramas de atividades
  - `arch_*.pdf` -> Diagramas de visões de arquitetura
  - `ui_*.png` -> Protótipos de tela / wireframes
